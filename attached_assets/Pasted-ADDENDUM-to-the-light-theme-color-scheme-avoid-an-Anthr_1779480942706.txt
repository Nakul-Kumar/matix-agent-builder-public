ADDENDUM to the light-theme color scheme — avoid an Anthropic-like aesthetic.

The previous prompt sets a warm cream background with a terracotta accent, which is the same broad palette family Anthropic uses on its marketing site. The point of this design is to read as editorial / architectural, NOT as an Anthropic clone. Adjust the following so the result is clearly differentiated:

1) PUSH TERRACOTTA TOWARD EARTHEN BRICK, NOT CORAL/PEACH

The Anthropic accent reads as a soft coral / salmon (warm, light, slightly pink). Ours must read as a deeper, drier, more pigmented BRICK/CLAY. Update --accent tokens:

   --accent:         #A24A26   /* deeper, drier brick — was #B8542E */
   --accent-hover:   #8C3D1C
   --accent-soft:    #DDB8A0   /* keep this restrained — use sparingly, not as a big fill */
   --accent-on-fill: #F5ECD8   /* warm cream text on the brick fill — NOT pure white, NOT a peachy cream */

If the cream-on-brick contrast still reads soft and Anthropic-y in a screenshot, deepen --accent further toward #8E3D1A. We want a color that looks like fired clay or oxidized iron, not a peach-coral pop.

2) SHIFT THE CREAM AWAY FROM ANTHROPIC'S WARM PAPER

Anthropic's cream is a warm yellow-leaning paper (~#F0EAE0). Pull ours slightly cooler and more gray-leaning so it doesn't sit in the same temperature band:

   --bg-base:        #ECE6D5   /* cooler, more linen-toned cream — was #F1E8D8 */
   --bg-elevated:    #F2EDDD
   --bg-recessed:    #E2DBC8
   --surface-card:   #F4EFE0
   --surface-card-2: #ECE5D2

These read as "architect's tracing paper" rather than "Claude marketing site cream."

3) USE TERRACOTTA SPARINGLY

Anthropic uses its accent liberally — headlines, big fills, hero illustration. Ours should be RESTRAINED:
- Buttons: yes, terracotta fill.
- Active states (tab border, side nav left rail): yes, terracotta stripe.
- Numeric meta values (TRUST, MATCH, item counts): yes, terracotta.
- Category labels (CODEX, SKILL, MCP, etc.): yes, mono caps in terracotta.
- DO NOT use terracotta for any large area fill, hero text headline, or background panel. Cream + dark text is the dominant visual; terracotta is the punctuation.
- The total terracotta surface area on any screen should be under ~6%. If you take a screenshot and the terracotta jumps out as the dominant impression, dial it back.

4) KEEP THE EDITORIAL DIFFERENTIATORS LOUD

The things that make this NOT-Anthropic stay in place and get emphasis:
- Fraunces (a quirkier serif than Anthropic's Tiempos/Styrene pairing) on display.
- JetBrains Mono caps for category labels — Anthropic doesn't use mono labels.
- Numeric prefixes on the side nav (01, 02, 03, 04) — this architectural numbering is a clear stylistic signal away from Anthropic.
- The dusty, painterly blob decoration — Anthropic uses clean line illustrations, not amorphous shapes. Keep ours blobby and watercolor-textured.

5) DECORATION COLOR DOUBLE-CHECK

The decor tokens from the previous prompt are correct in principle, but verify in a screenshot: if any blob reads as the same coral family as the accent, swap it for one of the more clearly distinct tones:
   --decor-1: #A89A7A   /* darker warm taupe */
   --decor-3: #8FA084   /* deeper sage — pushes greener, away from terracotta family */
   --decor-5: #9C8472   /* deeper warm walnut */
The blobs should provide chromatic counterweight to the terracotta, not echo it.
