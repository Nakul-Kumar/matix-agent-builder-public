## WHAT "VIBE CODED" MEANS — AND WHAT TO AVOID

The current design has the following AI-default clichés to eliminate:
  ✗ Gradient-filled display text (most common AI design tell)
  ✗ Oversized Inter font at 72px+ with default tracking
  ✗ Blue-to-purple color scheme (most common AI dark theme output)
  ✗ shadcn/Radix default badge/tag styling with no customisation
  ✗ Excessive card padding that makes everything feel airy and unfinished
  ✗ Glass morphism (no backdrop-filter: blur, no frosted panels)
  ✗ Gradient backgrounds or glowing orbs
  ✗ Line-breaking the hero text for dramatic effect across 3 lines

These patterns make the UI look auto-generated. Replace every one of them.

## 5. EXPLICIT DO-NOT-DO LIST

These will make the design vibe-coded. Do not use any of these:
  ✗ backdrop-filter: blur() — no glass morphism
  ✗ background gradients on any surface or background
  ✗ gradient fills on any text (no -webkit-background-clip: text)
  ✗ box-shadow with colour tints (e.g. no blue glows, no coloured halos)
  ✗ border-radius above 8px on any container
  ✗ font-size above 48px anywhere on the page
  ✗ animation or transition on page load (no fade-ins, no slide-ups)
  ✗ rounded-full / pill shapes on the platform tags
  ✗ any purple, indigo, violet, or cyan colour values
  ✗ Inter at default tracking (always set explicit letter-spacing)
  ✗ more than 2 font weights in use (600 and 400 only, except labels at 500)
