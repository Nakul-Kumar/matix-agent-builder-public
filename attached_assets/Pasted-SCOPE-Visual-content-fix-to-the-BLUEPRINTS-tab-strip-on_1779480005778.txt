SCOPE: Visual + content fix to the BLUEPRINTS tab strip only. No API, no routing, no data-shape changes.

PROBLEM
The three blueprint tab triggers currently render the full agent title inside each tab ("Codex Data Analyst Agent That Queries Agent", "Claude Code Data Analyst Agent That Queries Agent", "OpenClaw Data Analyst Agent That Queries Agent"). This:
1. Repeats the same string three times — visual noise, no information gain.
2. Wraps to two lines and makes the tabs feel like cards, not selectors.
3. Wastes the tab strip — the differentiating info (runtime, status, trust, match) gets buried below the redundant title.

FIX — restructure each tab trigger so it shows only what's distinct per runtime.

Each of the three tab triggers should render in this order, top to bottom:

1. Runtime name — Fraunces, weight 600, 18px, white (#F4EBE0 or your existing primary text color). This is the PRIMARY label of the tab.
   - Codex tab: "Codex"
   - Claude Code tab: "Claude Code"
   - OpenClaw tab: "OpenClaw"

2. Status pill + meta row — single row below the runtime name, mono caps 10px, muted text color, separated by middle dots. Format:
   ● PREVIEW · TRUST 74 · MATCH 92
   The colored dot keeps its existing status color (green for preview, neutral for planned, amber for experimental). Mono caps for the labels, terracotta for the numeric values as a subtle accent.

REMOVE from the tab trigger entirely: the long "Codex Data Analyst Agent That Queries Agent" title. That title belongs in the active blueprint panel header below the tab strip — not inside the tab itself.
