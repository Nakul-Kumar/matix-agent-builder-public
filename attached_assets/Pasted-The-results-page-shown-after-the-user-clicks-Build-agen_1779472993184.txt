Section 1 — Define a universal Result Card component.

Create a single reusable component (e.g. ResultCard.tsx in src/components/) that exactly mirrors the START FROM card pattern. Props:
- category: string (mono caps label, terracotta primary #C2674A, 10px, letter-spacing 0.14em)
- title: string (Fraunces 16px weight 600, color #EDE6DE)
- preview: string (sans 13px, color #A8998C, single-line ellipsis truncation: white-space nowrap, overflow hidden, text-overflow ellipsis)
- footnote: string (mono caps 10px, letter-spacing 0.14em, color #6E6359, right-aligned)
- onClick (optional): handler — if present, cursor pointer + hover treatment; if absent, static card
- href (optional): if present, wrap the card in an anchor tag opening in _blank

Card styling identical to START FROM cards:
- Background #14181C
- Border 1px solid #1F2429
- Border radius 4px maximum
- Padding 14px
- Min-height 120px
- Display flex, flex-direction column
- Row spacing inside the card: category to title 4px margin-top, title to preview 4px margin-top, preview to footnote 8px margin-top
- Hover (when interactive): border becomes #C2674A, inset box-shadow inset 2px 0 0 #C2674A on the left edge, translateX(2px) shift, transition all 160ms ease
