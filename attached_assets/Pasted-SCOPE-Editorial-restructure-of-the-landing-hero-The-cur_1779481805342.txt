The fix is to shrink the headline, add real editorial metadata, add a specific dek, and break the layout into an asymmetric two-column lockup. No changes to functionality, the textarea below, or any data — this is hero presentation only.

FOUR CHANGES — apply all four together

1) SHRINK THE HEADLINE
The current headline is sized so large it consumes the viewport. Drop the size by roughly 35–45%:
   - From whatever clamp/font-size it currently uses to: clamp(48px, 5.5vw, 84px)
   - Keep Fraunces, weight 600, line-height 1.05.
   - The headline should now occupy roughly the upper-left half of the viewport, NOT the full width.

2) REPLACE THE PHRASING
"One prompt. Three ready-to-use agents." reads as generic. Replace with something more editorial and specific:

   Describe your agent once.
   Get three runtimes worth keeping.

Two lines. Same Fraunces serif. The second line in slightly muted color (--text-body instead of --text-primary) so the first line lands harder. This still says the same thing but doesn't pattern-match the "X. Y." pitch-deck cliché.

3) REPLACE THE TOP "CODEX · CLAUDE CODE · OPENCLAW" STRIP WITH REAL EDITORIAL METADATA
The runtime list at the top is decoration. Replace it with a small editorial metadata block — same mono caps 10px treatment, but actual signal:

   ISSUE 001 · MAY 2026 · MATIX AGENT BUILDER

(Or, more specifically: a build-counter if you have one — "BUILD 0142 · MAY 2026 · MATIX". A real-feeling number, even if it's a fixed string, looks publication-like rather than feature-list-like.)

Position: top-left, above the headline. Followed by a 1px hairline (--border-hairline, 64px wide, NOT full-width) sitting 12px below it. The hairline is a strong editorial signal — magazines use it constantly, SaaS heros don't.

4) ADD AN ASYMMETRIC TWO-COLUMN LOCKUP

Restructure the hero as a 12-column grid:

   Left column (8/12): the editorial metadata strip, the hairline, the two-line headline, and a one-paragraph dek BELOW the headline.

   Right column (3/12, with 1/12 gap): a small vertical metadata stack — three to five micro-lines, each on its own row, mono caps 10px --text-muted, separated by 12px vertical gaps:

      RUNTIME TARGETS — 03
      AVG BUILD TIME — 7s
      EXPORT FORMAT — JSON
      LICENSE — MIT
      VERSION — 0.4.1-preview

   (Use real values if you have them; otherwise these are fine as static editorial scaffolding. The POINT is the format — a publication-style sidebar reads as intentional design, not generated copy.)

   Right column also has a left hairline (1px solid --border-hairline) running vertically, separating the sidebar from the headline column. 32px padding to the left of the sidebar content.

Specific, concrete, names the actual outputs. This sentence does the work the bare headline can't.
