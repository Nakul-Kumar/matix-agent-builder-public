## 1. COLOR SYSTEM — 60/30/10 RULE

Apply this strictly. Three color families, each with shade variance. No other hues allowed.

### 60% — DOMINANT (backgrounds & surfaces)
All backgrounds and containers use shades from this dark navy family only:
  --bg-base:     #080C17   (page background)
  --bg-surface:  #0E1221   (card/container backgrounds)
  --bg-elevated: #151A2D   (inputs, dropdowns, code chips)
  --bg-hover:    #1C2338   (hover states on surfaces)

### 30% — SECONDARY (text, borders, structural chrome)
All text and borders use shades from this slate family only:
  --text-primary:   #E2E8F5   (headings, strong labels)
  --text-secondary: #8E9BB5   (body copy, descriptions)
  --text-muted:     #4E5A74   (helper text, captions, counters)
  --border-subtle:  #141B2D   (barely-there dividers)
  --border-default: #1E2B44   (card borders, input borders)
  --border-strong:  #2A3855   (focused/active borders)

### 10% — ACCENT (actions, highlights, brand moments)
All interactive or brand-coloured elements use shades from this indigo/violet family only:
  --accent-base:    #6366F1   (primary button bg, active tags)
  --accent-light:   #818CF8   (button hover, icon highlights)
  --accent-dim:     #2D2B7A   (badge/tag background tint)
  --accent-border:  #4845A8   (badge/tag border)
  --accent-glow:    rgba(99, 102, 241, 0.15)  (focus rings, subtle glows)

No other colours (no coral, no cyan, no amber) — not even as gradients.

## 5. VALIDATION REQUIREMENTS (the redesign must pass all of these)

These are based on Nielsen's 10 Heuristics and WCAG 2.2 AA:

1. CONTRAST: --text-primary (#E2E8F5) on --bg-surface (#0E1221) must be ≥ 4.5:1. 
   Verify with https://webaim.org/resources/contrastchecker/
2. LARGE TEXT: --text-secondary (#8E9BB5) on --bg-surface must be ≥ 3:1 for any 
   text 18px+ (WCAG large text threshold)
3. SYSTEM STATUS (Heuristic #1): The "Build agent" button MUST show a loading/busy 
   state while waiting for a response. No silent waiting.
4. CONSISTENCY (Heuristic #4): All three platform badge tags (CODEX, CLAUDE CODE, 
   OPENCLAW) must be visually identical — no variation in style between them.
5. COLOUR BLINDNESS: No information conveyed by colour alone — the star rating 
   must use filled/unfilled shapes, not just colour change.
6. PURE BLACK/WHITE AVOIDANCE: Do not use #000000 or #FFFFFF anywhere — pure 
   black causes halation artifacts on OLED screens, pure white blooms at night.
7. NO NEW HUES: Run a visual check — only navy/charcoal, slate, and indigo/violet 
   should appear. If any other hue is visible, remove it.
